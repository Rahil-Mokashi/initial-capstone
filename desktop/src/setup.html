Single PC

This PC keeps its own data and works on its own, exactly as before. This is the normal choice for one computer.

Client PC

Use the pump's Main PC over the network. This PC keeps no data of its own. The owner presses "Add a device" on the Main PC and gives you a code.

The Main PC introduced itself with this fingerprint. It must be the same as the one shown on the owner's screen:

Main PC

The Main PC is set up once by whoever installs the system, in an Administrator PowerShell, with scripts\lan\install-main-pc.ps1. It keeps the database and runs all day, with or without a window.

The Main PC's own window is a Client too: after installing, run pperp_api.exe lan enrol-local --name "Main PC window" --out device.json, then use "Import a device file" above.
